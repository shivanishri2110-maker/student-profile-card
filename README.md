# Student Profile Card

A responsive frontend mini project made with HTML, CSS, and JavaScript. It displays a student profile card with a photo, name, department, year, skills, and social links. Use **Edit profile** to change the details; choose the photo button to upload a profile image. Changes are saved in the browser's local storage on that device.

## Run it

1. Download or clone this folder.
2. Open `index.html` in a browser. No package installation or server is required.
3. Select **Edit profile** to update the sample name, department, year, skills, and LinkedIn/GitHub URLs. Select the plus button on the photo to choose an image (up to 2 MB).

## Files

- `index.html` — profile card and edit form
- `style.css` — responsive card styling
- `script.js` — editing, photo upload, and local browser saving
